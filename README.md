# Epson EH-TW5350 Security Advisories (B-BEAM-BOB)

Three vulnerabilities discovered in the Epson EH-TW5350 projector (firmware
150075647YWWV110) by team B-BEAM-BOB during the KITRI Best of the Best (BoB)
program, 2021. CVE IDs were assigned by MITRE on 2021-12-21 but the records
were never published. This repository serves as the public disclosure
reference required to complete that publication.

| Advisory | CVE ID | Type |
|---|---|---|
| [CVE-2021-43716](./CVE-2021-43716.md) | CVE-2021-43716 | Firmware update verification bypass |
| [CVE-2021-43717](./CVE-2021-43717.md) | CVE-2021-43717 | Use of hard-coded credentials |
| [CVE-2021-43718](./CVE-2021-43718.md) | CVE-2021-43718 | Web Control authentication bypass |

## Team

B-BEAM-BOB, KITRI Best of the Best (BoB) — Jae-Yong Lee, Seung-Min Kang,

## Disclosure timeline

- 2021-11: Vulnerabilities discovered and internally documented.
- 2021-11: Reported to Epson.
- 2021-12-21: CVE IDs assigned by MITRE (ticket scr1172475), pending
  publication.
- 2026: Public advisories published to complete the CVE record publication
  process.
